How to Connect Your App (API Guide)

Think of an API like a waiter at a restaurant. Your app asks the waiter for information (like a student list), the waiter goes to the kitchen (our database), and brings back your order.

Server Web Address (Base URL):

https://ipt02-student-directory.netlify.app/api
Important for Ionic Angular: Make sure you import provideHttpClient() in your app.config.ts (or HttpClientModule in app.module.ts) before calling these methods in your service.

URL to call: /api/register

Ionic TypeScript Example:

registerStudent() {
  const body = {
    registration_token: "YOUR_CLASS_TOKEN", //Ask your instructor for this token
    student_id: "2026-0001",
    student_name: "Juan Dela Cruz",
    password: "YourPassword123",
    section: "BSIT-3Z",
    email: "juan@example.com",
    mobile_number: "09123456789",
    social_media_link: "https://facebook.com/juan",
    profile_picture_url: "https://via.placeholder.com/150"
  };

  this.http.post('https://ipt02-student-directory.netlify.app/api/register', body)
    .subscribe({
      next: (res: any) => console.log('Registered successfully!', res),
      error: (err) => console.error('Registration failed:', err)
    });
}

URL to call: /api/login

What is a JWT Token? It's a digital security pass returned when you log in. Save it in localStorage so you can attach it to future requests.

Ionic TypeScript Example:

loginStudent() {
  const credentials = {
    student_id: "2026-0001",
    password: "YourPassword123"
  };

  this.http.post('https://ipt02-student-directory.netlify.app/api/login', credentials)
    .subscribe({
      next: (res: any) => {
        // Save the JWT security token in browser storage
        localStorage.setItem('auth_token', res.token);
        console.log('Logged in! Token saved:', res.token);
      },
      error: (err) => console.error('Login failed:', err)
    });
}

URL to call: /api/students

Retrieve your saved token and send it in the Authorization header:

getStudents() {
  const savedToken = localStorage.getItem('auth_token');

  const headers = new HttpHeaders({
    'Authorization': `Bearer ${savedToken}`
  });

  this.http.get('https://ipt02-student-directory.netlify.app/api/students', { headers })
    .subscribe({
      next: (data: any) => {
        this.students = data;
        console.log('Students loaded:', data);
      },
      error: (err) => console.error('Failed to load students:', err)
    });
}

URL to call: /api/students/2026-0001

Ionic TypeScript Example:

updateProfile(studentId: string) {
  const savedToken = localStorage.getItem('auth_token');

  const headers = new HttpHeaders({
    'Authorization': `Bearer ${savedToken}`
  });

  const updatedData = {
    student_name: "Juan Dela Cruz Jr.",
    section: "BSIT-3Z",
    email: "juan.updated@example.com",
    mobile_number: "09998887766"
  };

  this.http.put(`https://ipt02-student-directory.netlify.app/api/students/${studentId}`, updatedData, { headers })
    .subscribe({
      next: (res: any) => console.log('Profile updated!', res),
      error: (err) => console.error('Update failed:', err)
    });
}
Simple Troubleshooting & Fixes
1. How to See Hidden Error Messages

If your app is stuck or not responding, press F12 on your keyboard (or Right-Click on the page and select Inspect):

  • Console Tab: Look here for red error messages describing what went wrong in your code.
  • Network Tab: Shows every request sent to the server. Click any item highlighted in red to read the exact error message sent back by the server.
2. What Do These Error Numbers Mean?
NumberMeaningHow to Fix It
200 / 201Success!Everything worked perfectly.
400Missing DetailsYou forgot to fill out a required box (like student ID or password).
401Access DeniedYou forgot to include your digital key (JWT Token) from logging in, or it expired.
403Wrong Security CodeYour class registration token is incorrect, or you are trying to edit someone else's account.
500Server ProblemSomething unexpected broke on the server side. Contact your instructor.
3. Testing Your Connection

If you get an error saying "Failed to fetch" or "Network Error":

  • Check your internet connection.
  • Open this web link directly in a new browser tab to check if the server is active:
    https://ipt02-student-directory.netlify.app/api/students
  • Ping Database Host directly in Windows Powershell to check if the database service is running:
    Test-NetConnection -ComputerName ipt-02-student-directory-ipt02-student-directory.f.aivencloud.com -Port 24876
